# cpp-board-game

## Overview
- A customizable, turn-based board game developed in C++ as part of a programming course assignment.

## Features
- Custom game theme and messages
- Player movement across a game board
- Player scoring system
- Custom victory conditions
- Improved board display

## Technologies
- C++

## Concepts Demonstrated
- Object-oriented programming
- Classes and functions
- Game logic and conditional statements
- Modifying and extending an existing codebase

## Academic Context
- Originally developed as coursework and adapted to demonstrate C++ programming skills.
